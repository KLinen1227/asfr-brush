# ASFR笔刷0.0.1

> 声明：该插件及项目页由 GPT-6 Astra 生成。

**维护与配布：KLinen**

ASFR笔刷是一款 Blender 局部材质绘制插件。它可以在模型上涂抹石化、硬质化、冰霜和黄金效果，并通过时间路径控制效果的出现顺序。

## 功能

| 功能 | 用途 |
| --- | --- |
| 球形穿透笔刷 | 同时涂抹球形范围内的外层、背面与内部表面 |
| 表面笔刷 | 涂抹当前视角可见的外层表面 |
| 多角度连续绘制 | 暂停绘制、调整视角后继续记录同一条路径 |
| 时间路径 | 支持同时渐变、按绘制顺序、各段同时推进 |
| 路径管理 | 启用、独显、批量偏移时间、仅擦除勾选路径 |
| 材质预设 | 默认石头、人形硬质化、冰霜冻结、黄金化 |
| 外观记忆 | 按模型和预设记忆参数，支持独立重置 |
| 人物细节混合 | 混合可识别的人物原有法线、凹凸与效果材质细节 |
| 轻量预览 | 简化绘制期间的材质显示，正式输出使用完整效果 |

## 下载与安装

在项目 **Releases → Assets** 中下载 **ASFR-Brush-0.0.1.zip**。
这是 ASFR笔刷0.0.1 的 Blender 安装包。**Source code (zip)** 是项目源码归档，不能直接作为插件安装包使用。

1. 保存当前 Blender 工程。
2. 打开 **编辑 → 偏好设置 → 插件 → 从磁盘安装**，选择安装包，无需解压。
3. 启用 **ASFR笔刷0.0.1**。更新已安装的版本后，请保存工程并重启 Blender。
4. 在 3D 视图按 **N**，打开 **ASFR** 侧栏。

本版本采用传统 Python add-on 安装方式，无需额外安装 Python 或 pip 依赖。

## 第一次使用

1. 选择角色网格、骨骼或根物体，点击 **使用当前选择的模型**。
2. 检查目标范围，首次使用点击 **初始化 / 升级目标模型**。
3. 在 **材质预设** 中选择并应用一种效果。
4. 选择 **球形穿透** 或 **表面涂抹**，调整笔刷半径。
5. 选择静态涂抹或时间路径。按住左键绘制，松开暂停；使用中键调整视角后可继续绘制。
6. 按 **Enter** 完成，按 **Esc** 取消。完成一次绘制后，可用 **Ctrl+Z** 撤销。

详细操作见 [使用说明书](docs/USER_GUIDE.md)，常见操作疑问见 [常见问题](docs/FAQ.md)。

## 使用注意

- 已验证环境：**Blender 4.5.5、Windows x64**。其他系统及 Blender 版本尚未逐一验证。
- 绘制精度受网格密度影响；球形穿透笔刷与表面笔刷的作用范围不同。
- 使用修改器兼容流程时，绘制后应保持模型拓扑和细分级别稳定。随时间改变拓扑的修改器可能影响结果。
- 冰霜预设会生成冰层和冰锥几何，数量及场景复杂度会影响性能。
- 批量材质操作会暂存数据，以便失败时恢复，可能增加内存占用。
- 插件用于材质与附加几何效果，原有骨骼动画保持运行。
- 安装包不包含人物模型、角色贴图、音乐或演示工程。
