# ASFR笔刷

> 声明：该插件及项目页由 GPT-6 Astra 生成。

**公开署名 / 维护与配布：KLinen。**

在 Blender 模型上涂抹局部材质效果，并将变化过程与时间轴关联。

**当前版本：ASFR笔刷0.0.1。** 本项目目前处于私有仓库准备阶段，尚未对外公开；公开署名、许可证及素材授权确认见 [发布状态](distribution/publication.json)。在这些事项确认前，不宣称项目已正式开源。

## 功能

| 功能 | 用途 |
| --- | --- |
| 球形穿透笔刷 | 球形范围内的外层、背面与内部一起涂抹 |
| 表面笔刷 | 只画当前视角可见的外层表面 |
| 多角度连续绘制 | 中途转动视角，继续画同一条路径 |
| 时间路径 | 同时渐变、按绘制顺序、各段同时推进 |
| 路径管理 | 启用、独显、批量偏移时间、仅擦除勾选路径 |
| 材质预设 | 默认石头、人形硬质化、冰霜冻结、黄金化 |
| 外观记忆 | 每模型、每预设记住参数，另有重置按钮 |
| 人物细节混合 | 将可识别的原法线/凹凸与效果材质细节混合 |
| 轻量预览 | 简化绘制期间的材质显示，正式输出恢复完整材质 |

## 下载与安装

仓库公开后，在 **Releases → Assets** 下载手动附加的 **ASFR-Brush-0.0.1.zip**（ASFR笔刷0.0.1 安装包）。
不要把 GitHub 自动生成的 **Source code (zip)** 当作安装包：它包含整个项目目录，不是 Blender 所需的插件目录结构。

安装包另存于本地 `release-assets/`，不纳入 Git 提交，并作为 Release 草稿附件上传。仓库保持私有时，未获授权的用户无法访问项目与附件。

1. 保存当前 Blender 工程。
2. 打开 **编辑 → 偏好设置 → 插件 → 从磁盘安装**，选择上述 ZIP。
3. 启用 **ASFR笔刷0.0.1**；升级旧版时保存后重启 Blender。
4. 在 3D 视图按 **N**，打开 **ASFR** 侧栏。

这是传统 Python add-on 安装包，不是 Blender Extensions 格式。无需额外安装 Python 或 pip 依赖。

## 第一次使用

1. 选择角色网格、骨骼或根物体，点击 **使用当前选择的模型**。
2. 检查目标范围，首次使用点击 **初始化 / 升级目标模型**。
3. 在 **材质预设** 中选择并应用一种效果。
4. 选择 **球形穿透** 或 **表面涂抹**，调整笔刷半径。
5. 选择静态涂抹或时间路径。左键画，松开暂停，中键旋转后继续。
6. **Enter 完成，Esc 取消，Ctrl+Z 撤销已完成的一次绘制。**

详细操作见 [使用指南](docs/USER_GUIDE.md)，遇到问题先看 [常见问题](docs/FAQ.md)。

## 兼容性和边界

- 已验证环境：**Blender 4.5.5、Windows x64**。其他系统及 Blender 版本尚未逐一验证。
- 绘制精度受网格密度影响；球形笔刷会穿透，表面笔刷不会。
- 支持既有固定拓扑兼容流程，但不能保证任意随时间改变拓扑的修改器都可用。绘制后保持拓扑及细分级别稳定。
- 冰霜预设会额外生成冰层和冰锥几何；数量及场景复杂度影响性能。
- 批量材质切换会临时暂存数据以便失败回滚，可能增加内存占用。
- 本插件主要改变外观；**不实现局部刚性冻结或渐进解冻，不停止骨骼动画**。
- 不包含人物模型、角色贴图、音乐或第三方演示工程。
