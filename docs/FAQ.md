# 常见问题

## 下载了 ZIP 却安装不了

请使用 Releases 下手动附加的 ASFR 安装包，不要使用 Source code (zip)。安装包顶层应是 `petrify_painter/`，其中有 `__init__.py`。本地开发者可以用构建脚本生成正确结构。

## 安装后找不到面板

确认插件已启用，并在 3D 视图打开 N 侧栏中的 ASFR。升级后需要先保存，再重启 Blender；磁盘上的更新不会自动替换当前进程已加载的代码。

## 没有涂抹的地方为什么也生效了

球形穿透会同时影响球体范围内背面和内部表面。只想画可见外层时，切换到表面涂抹。

## 绘制中为什么不是最终材质

绘制中用灰色范围预览覆盖区域，完成后显示效果材质。轻量预览也不会完整呈现金属、树脂、冰层或法线细节。

## 独显之后其他模型的路径也不见了

独显筛选当前场景登记的时间路径；其他未独显路径暂时不产生效果。关闭所有独显后恢复。静态范围与旧贴图蒙版不受独显影响。

## “勾选”和“启用”有什么区别

左侧勾选用于批量平移或指定擦除；启用控制该路径是否生效。擦除选择“勾选路径”后，不会改其他路径或静态涂抹。擦除作用于整条路径的所有帧。

## 材质切回来参数还在，怎么恢复默认

这是外观记忆功能。使用“重置当前材质参数”，不会删除涂抹范围和时间路径。

## 角色没有法线贴图能用吗

可以。未识别到人物法线/凹凸时使用表面法线；效果材质仍能提供自身细节。复杂多分支材质无法唯一识别时会给出回退提示。

## 卡顿或修改器不兼容怎么办

先尝试轻量预览、减少冰锥数量，检查模型面数、路径数量和其他重型修改器。预览和渲染细分级别应一致，绘制后不要改变拓扑。

## 会把动作也冻住吗

不会。石化、硬质化、黄金化主要是材质效果；冰霜预设增加冰层和冰锥，不等于冻结骨骼动作。
