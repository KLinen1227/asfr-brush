# 首次 GitHub 发布步骤

已获维护者授权，将配布版上传至 `KLinen1227/asfr-brush` 私有仓库；暂不公开、不添加许可证。

## 先确认三件事

1. 对外署名已确认为 **KLinen**；GitHub 账号使用维护者现有账号。建议仓库名为 `asfr-brush`，这不是已经占用或创建的线上地址，也不假定账号用户名就是 KLinen。
2. 代码和材质资产的许可。按 `LICENSE_STATUS.md` 核对，加入正式许可并同步安装包。
3. 最终上传范围及仓库是否公开，由维护者明确确认。

## 文件分别放在哪里

- 仓库：`petrify_painter/`、文档、测试和构建工具。
- Release 附件：已验证的 `ASFR笔刷0.0.1.zip` 和 `SHA256SUMS.txt`。
- 不上传：本机完整材质自用版、历史工作目录、个人模型、备份与用户设置。

当前 `release-assets/` 保存已验证安装包，仅在本地存在并被 Git 忽略。后续加入许可证等内容后应重新构建附件，不能把旧附件当作已经含有新许可文本。
远程仓库使用 `main` 分支。正式公开前再次检查上传范围；不要在提交中公开不希望披露的真实姓名、私人邮箱。

## 操作顺序

1. 完成署名、许可和资源核对；移除 README 的“本地准备稿”提示并填写真实项目地址（当前没有虚构地址）。
2. 运行公开内容检查、测试与构建；复核 ZIP 内文件，记录 SHA256。
3. 在 GitHub 登录自己的账号；创建仓库并确认可见性。不把账号密码或验证码写入项目。
4. 仅提交当前独立项目的文件；推送前检查文件清单。不要把上级工作目录拖进去。
5. 建立 `v0.0.1` 标签，对应审核后的代码提交。
6. 进入 Releases，新建草稿，标题用 `ASFR笔刷0.0.1`，正文可使用 `docs/RELEASE_v0.0.1.md`。
7. 附加正确的插件 ZIP 和校验文件，检查页面与附件后再手动公开。

GitHub 支持先保存 Release 草稿、添加安装包附件，再发布。[GitHub 官方发布说明](https://docs.github.com/en/repositories/releasing-projects-on-github/managing-releases-in-a-repository)

GitHub 自动提供的 Source code (zip) 是整个仓库的源码归档，不是本项目为 Blender 组装的安装 ZIP。请在下载说明中明确区分。
