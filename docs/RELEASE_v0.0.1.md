# ASFR笔刷0.0.1

> 声明：该插件及项目页由 GPT-6 Astra 生成。

Blender 局部材质绘制与时间路径插件。维护与配布：KLinen。

## 安装

下载附件 **ASFR-Brush-0.0.1.zip**，在 Blender 的 **编辑 → 偏好设置 → 插件 → 从磁盘安装** 中安装并启用。无需解压，也不要使用 **Source code (zip)** 作为安装包。

在 3D 视图按 **N**，打开 **ASFR** 侧栏。完整使用说明书包含在安装包中，也可在仓库的 `docs/USER_GUIDE.md` 查看。

## 功能

- 球形穿透与表面涂抹，支持多角度连续绘制。
- 同时渐变、按绘制顺序、各段同时推进三种时间模式。
- 默认石头、人形硬质化、冰霜冻结、黄金化四款材质预设。
- 按模型和预设记忆外观参数，支持独立重置。
- 路径启用、独显、批量时间偏移及指定路径擦除。
- 人物法线细节混合、轻量预览及批量操作失败回滚。

## 使用注意

- 已验证环境：**Blender 4.5.5 / Windows x64**。其他系统及 Blender 版本尚未逐一验证。
- 更新前保存工程，更新完成后重启 Blender。
- 绘制后应保持模型拓扑和细分级别稳定；复杂场景可使用轻量预览，并适当减少冰锥数量。
- 安装包不包含人物模型、角色贴图、音乐或演示工程。
