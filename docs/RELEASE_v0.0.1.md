# ASFR笔刷0.0.1

Blender 局部材质涂抹与时间路径工具。已验证环境：Blender 4.5.5 / Windows x64。

## 下载

安装请下载附件 **ASFR笔刷0.0.1.zip**，不要选择自动生成的 Source code (zip)。
保存工程后，在 Blender 的“偏好设置 → 插件 → 从磁盘安装”中安装并启用，入口为 **N 面板 → ASFR**。

## 功能

- 球形穿透与表面涂抹；默认多角度连续绘制。
- 同时渐变、按顺序推进、各段同时推进三种时间模式。
- 默认石头、人形硬质化、冰霜冻结、黄金化四款预设。
- 各模型的材质参数记忆与独立重置。
- 路径启用、独显、批量平移、指定路径擦除。
- 相关目标刷新、批量操作失败回滚、人物法线细节混合及轻量预览。

## 注意

升级后保存并重启 Blender。绘制后应保持拓扑和细分级别稳定；复杂场景可尝试轻量预览。
本版不包含人物模型或第三方演示资源，不实现局部刚性冻结或渐进解冻。其他系统和 Blender 版本尚未逐一验证。
