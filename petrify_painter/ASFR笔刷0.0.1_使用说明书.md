## 1 安装与打开面板

### 1.1 安装插件

1. 保存当前 Blender 工程。
2. 打开 **编辑 → 偏好设置 → 插件**。
3. 在右上角菜单中选择 **从磁盘安装**。
4. 选择 `ASFR笔刷0.0.1.zip`，完成安装。
5. 在插件列表中搜索 `ASFR`，启用 **ASFR笔刷0.0.1**。
6. 返回 3D 视图，将鼠标移入视图，按 **N** 打开侧栏，选择 **ASFR** 标签。

使用配布页面提供的插件安装包，不要将 GitHub 自动生成的 `Source code (zip)` 当作安装包。正确的插件 ZIP 内包含 `petrify_painter` 文件夹，文件夹中有 `__init__.py`。

### 1.2 从已有版本升级

升级前备份工程和自定义预设，再安装新包。安装后保存工作并重启 Blender，让新代码生效。

插件内部模块名仍为 `petrify_painter`。同一 Blender 环境中只启用一份，不要通过改文件夹名称同时启用多个副本。

### 1.3 面板分区

| 位置 | 主要内容 |
| --- | --- |
| 3D 视图 → N → ASFR → 主面板 | 目标模型、初始化、预览、笔刷、时间路径、材质参数和保存 |
| 3D 视图 → N → ASFR → 预设管理 · 添加 / 删除 | 保存、删除、恢复及管理自定义预设 |
| 3D 视图 → N → ASFR → 高级工具 → 旧版工程维护 | 修补早期工程的贴图蒙版 |
| 着色器编辑器 → N → ASFR → 材质预设 | 将当前选中的着色器组节点保存为预设 |

未初始化的目标只显示准备所需的选项。初始化完成后，笔刷和材质设置才会出现。

## 2 目标模型与初始化

### 2.1 选择绘制目标

可以将网格物体、骨骼物体或角色根空物体设为目标。

1. 在场景中选中目标。
2. 点击 **使用当前选择的模型**。
3. 检查面板上方的 **目标模型** 和 **本次范围：× 个可见网格**。

对于有父子关系的角色，按钮可能自动将目标定位到骨骼或 MMD 根节点。若只想处理一个具体网格，可在 **目标模型** 字段中直接指定该网格，并关闭 **包含模型子物体**。

**包含模型子物体** 开启时，目标及其下级网格会一并纳入范围，例如同一角色的身体、衣服、头发和配饰。关闭后只处理目标自身的网格；骨骼或空物体本身没有可绘制表面。

插件筛选当前视图层中可见、具有面且未关闭渲染显示的网格，排除 MMD 刚体、关节以及插件生成的冰层对象。某个部件没有纳入范围时，应先检查它的父子关系、可见性和渲染开关。

### 2.2 初始化模型

首次处理目标时，选择 **蒙版分辨率**，点击 **初始化 / 升级目标模型**。

初始化会准备效果材质连接、独立蒙版及绘制所需数据。多网格目标会先进行检查；本批处理失败时，插件会尝试回滚本批修改，并报告原因。

蒙版分辨率可选 **2K、4K、8K**，默认 **4K**。该选项用于初始化的贴图蒙版。主面板的球形穿透和表面涂抹使用网格属性记录范围，细节精度主要取决于网格密度，不能单靠提高蒙版分辨率改善。

初始化报错时，按提示检查：

- 目标是否有可见网格和有效的面。
- 链接模型是否已转为可编辑的本地数据。
- 材质是否有连接到表面输入的材质输出节点。
- 网格是否还有可用的 UV 层。
- 修改器设置是否满足第 11 章的要求。

### 2.3 切换模型

完成或取消当前绘制后，重新选择角色并点击 **使用当前选择的模型**。已绘制数据留在原目标上，不会因为切换目标而清除。新的目标若尚未初始化，需要先初始化。

切换目标后，面板会读取目标的外观参数，并按目标尺寸重新设置笔刷半径。开始下一次绘制前应检查半径。

目标包含多个网格时，面板从其中第一个有效网格读取显示值；通过面板修改外观参数会作用于当前目标范围内的适用网格。只想单独调整某个部件时，应先缩小目标范围。

## 3 首次绘制

以下步骤可完成一次静态石化绘制：

1. 选定模型并完成初始化。
2. 展开 **材质预设**，选择 **默认石头**，点击 **应用材质预设**。
3. 在 **使用方法** 中选择 **表面涂抹**。
4. 在 **绘制方式** 中选择 **静态涂抹**。
5. 调整 **笔刷半径**，保留 **多角度连续绘制** 开启。
6. 点击 **开始涂抹**，将鼠标移入模型区域，按住左键拖动。
7. 松开左键暂停，用中键旋转视角，再按左键继续绘制。
8. 按 **Enter** 完成。绘制时的灰色范围会转换为当前材质效果。
9. 调整石头颜色、粗糙度等参数。
10. 点击 **保存工程和石化蒙版**。

想取消本次尚未完成的绘制，按 **Esc** 或鼠标右键。已经按 Enter 完成的操作，可用 **Ctrl+Z** 撤销。

## 4 笔刷与多角度操作

### 4.1 两种使用方法

| 方法 | 作用范围 | 操作要点 |
| --- | --- | --- |
| 球形穿透 | 球形范围内当前目标的表面、内部和背面 | 适合让衣服与内部身体一起产生效果；注意附近其他部件也可能进入范围 |
| 表面涂抹 | 当前目标范围内，朝向视角且未被目标表面遮挡的外层 | 适合控制局部外表面；背面需转动视角后另画 |

两种方法均支持静态涂抹、时间路径、多角度连续绘制和擦除。**表面涂抹** 是主面板的绘制方法，与“旧版工程维护”中的贴图修补工具不同。

### 4.2 笔刷参数

| 参数 | 含义与调整方式 |
| --- | --- |
| 笔刷半径 | 世界空间中的绘制半径，不是屏幕像素大小。模型尺寸不同，需要分别调整 |
| 球心深入 | 仅球形穿透显示。沿视线将球心从命中表面向内移动，以当前半径为单位；0 在表面，1 深入一个半径，负值向外移 |
| 边缘硬度 | 范围为 0—1。较低值使边缘过渡柔和，较高值使覆盖边界更明确 |
| 笔刷强度 | 范围为 0.01—1。决定本次写入范围的权重；较低值使效果或擦除更弱 |

半径太小而网格过疏时，笔刷可能没有覆盖任何顶点。遇到“笔刷范围内没有可绘制顶点”的提示，先增大半径或调整视角。

单次绘制对同一顶点保留较强的覆盖值，并非鼠标停留越久就持续累加强度。需要更强的覆盖时，应提高 **笔刷强度**。

### 4.3 多角度连续绘制

**多角度连续绘制** 默认开启。一次操作可以包含多次按下、拖动和松开左键，直到按 Enter 才统一完成；时间路径模式下，这些笔段合为一条路径。

| 操作 | 结果 |
| --- | --- |
| 左键拖动 | 绘制或擦除 |
| 松开左键 | 暂停，并结束当前笔段 |
| 中键拖动 | 旋转视角 |
| Shift+中键拖动 | 平移视图 |
| 滚轮 | 缩放视图 |
| Enter / 小键盘 Enter | 完成本次操作 |
| Esc / 鼠标右键 | 取消本次尚未完成的操作 |
| 完成后 Ctrl+Z | 撤销已经提交的操作 |

暂停和转动视角不会在两段之间自动画出连接区域。关闭 **多角度连续绘制** 后，松开左键即完成一笔；下一笔需要再次点击开始按钮。

参数应在开始绘制前设置。绘制期间先用 Enter 完成或 Esc 取消，再修改面板参数。

### 4.4 绘制范围预览

绘制中使用独立覆盖层显示本次操作：

- **灰色**：本次绘制覆盖范围。
- **橙色**：本次擦除范围。
- 笔刷轮廓：表示当前笔刷位置及半径。

覆盖层用于检查范围，不代表最终材质。完成操作后才显示材质结果。取消本次操作时，尚未提交的覆盖层会被移除。

## 5 静态涂抹与时间路径

### 5.1 静态涂抹

选择 **静态涂抹** 后，已完成的范围在所有帧显示。静态结果不生成“已有时间路径”条目，修改范围使用擦除工具。

### 5.2 时间路径

选择 **时间路径**，设置时间模式及 **从 / 到**，再点击 **画一条时间路径**。

- **从**：路径的开始帧。
- **到**：路径的结束帧，不能小于开始帧。
- **过渡帧数**：在“按绘制顺序”和“各段同时推进”中显示，控制每个位置在预定完成帧之前逐渐显现的时间。

记录完成后，插件会跳到该路径的结束帧，便于检查完整覆盖范围。将时间轴拖回开始帧附近，再播放或逐帧查看变化。开始帧之前，该时间路径不显示；结束后保留完成结果。

开始绘制时，插件会停止正在播放的时间轴。绘制顺序用于确定效果推进的先后，不按实际落笔耗时录制动画；停顿时间不会原样变成动画中的等待时间。

### 5.3 同时渐变

同一次绘制的全部区域一起变化，从开始帧逐渐增强，到结束帧一起完成。不区分先画还是后画。

例如，将开始帧设为 1、结束帧设为 30，分别涂抹手臂、腿部和衣服后按 Enter。这三个区域会在第 1—30 帧一起渐变。

### 5.4 按绘制顺序

按照落笔顺序和路径上的位置推进效果。先画的部分先变化，后画的部分后变化。多次抬笔仍属于同一条连续的时间顺序，但抬笔之间没有额外绘制连接区域。

例如，从脚部开始，依次画小腿、大腿和躯干，最后按 Enter。播放时，效果按该顺序推进。

**过渡帧数** 较小时，推进边界较清楚；较大时，边界更柔和，邻近位置的变化会有更多重叠。该参数不延长路径设置的起止区间。

### 5.5 各段同时推进

一次按下左键到松开左键构成一个笔段。各笔段共用相同的开始帧和结束帧，但分别沿各自的绘制方向推进。

要让三个区域同时从左向右变化，可按以下步骤操作：

1. 开启 **多角度连续绘制**。
2. 选择 **时间路径 → 各段同时推进**。
3. 设置开始帧 1、结束帧 30。
4. 点击 **画一条时间路径**。
5. 在第一个区域从左向右绘制，松开左键。
6. 在第二个区域从左向右绘制，松开左键。
7. 在第三个区域从左向右绘制，松开左键。
8. 按 Enter 完成。

播放时，三个笔段同时推进。笔段长度不同，也会映射到同一个时间区间，因此实际推进速度可以不同。方向以各段真实绘制顺序为准；转动视角后，屏幕上的“左到右”不一定对应相同的模型空间方向。

同一区域被多个笔段反复覆盖时，每个顶点按较强的覆盖记录确定笔段归属。若希望三段各自清楚推进，应减少笔段之间的大面积重叠。

## 6 路径管理与擦除

### 6.1 查看和修改已有路径

展开 **已有时间路径**。列表显示与当前目标关联的路径，可以：

- 编辑路径名称。
- 修改时间模式。
- 修改开始帧、结束帧及适用模式下的过渡帧数。
- 控制启用、独显，或删除路径。

笔刷区的时间设置用于下一次绘制；调整已有路径应在对应路径条目中操作。修改已有路径的时间，不需要重新绘制覆盖范围。

部分早期路径没有记录笔段边界，条目会提示“旧路径未记录分段，新模式需重画”。这类路径不能直接切换为“各段同时推进”。

### 6.2 勾选、启用与独显

| 控件 | 用途 |
| --- | --- |
| 路径名称左侧勾选框 | 指定参与批量平移或定向擦除的路径，不控制显示 |
| 启用 | 暂时关闭或恢复该路径效果，保留路径数据 |
| 独显 | 当场景中存在“启用且独显”的路径时，仅这些时间路径产生效果 |

独显针对当前场景中登记的时间路径。另一个模型的路径即使没有显示在当前目标列表中，也可能被独显筛选隐藏。关闭所有有效独显后，其余已启用路径恢复显示。

静态涂抹和旧贴图蒙版不受时间路径独显筛选影响。

### 6.3 批量平移时间

1. 勾选需要移动的路径。
2. 在 **偏移帧** 中输入数值。
3. 点击 **平移勾选**。

正值将路径延后，负值将路径提前。开始帧和结束帧一起平移，持续时间不变。例如，原区间为 1—30，偏移 20 帧后为 21—50。

操作只处理当前目标范围内的勾选路径。每点击一次都会执行一次偏移；不是设置绝对的开始帧。未勾选路径或偏移结果超出允许范围时，插件会提示并取消操作。

### 6.4 擦除范围

擦除使用当前选定的球形或表面笔刷，半径、硬度和强度同样有效。

**全部涂抹**：擦除笔刷范围内的静态涂抹和所有时间路径，包含未勾选的路径。按钮为 **擦除全部涂抹（所有帧）**。

**勾选路径**：只擦除当前目标列表中勾选的时间路径，保留其他路径和静态范围。按钮为 **擦除勾选路径（所有帧）**。执行前必须勾选至少一条适用路径。

擦除修改的是整条路径的覆盖数据，作用于该路径的所有帧。当前停在哪一帧，不会把擦除限制在那一帧。较低笔刷强度会部分减弱覆盖；需要彻底擦除局部时可提高强度，并检查笔刷边缘是否覆盖完整。

上述两种擦除不处理旧贴图蒙版。旧蒙版的擦除入口见第 13 章。

### 6.5 删除路径

点击路径名称右侧的 **×**，删除整条路径及其关联的覆盖记录。若同一条路径跨越身体、衣服等多个网格，删除会同时移除这些网格上属于该路径的效果。

删除路径不清除静态涂抹，也不重置材质参数。只是暂时不显示某条路径时，使用 **启用** 开关即可。删除后可以用 Ctrl+Z 撤销。

## 7 内置材质预设

### 7.1 应用预设与参数记忆

ASFR笔刷0.0.1 包含四款内置预设：**默认石头、人形硬质化、冰霜冻结、黄金**。

展开 **材质预设**，在列表中选择后点击 **应用材质预设**。仅改变下拉框选项不会直接替换模型外观；应用后，以 **当前：……** 显示的名称为准。

预设作用于当前目标已有的绘制范围。切换预设保留涂抹与时间路径，外观参数按网格目标和预设分别记忆，再次切回时恢复。材质预设不是逐条时间路径分配的：同一目标切换外观后，其已有范围使用新的效果材质。

**重置当前材质参数** 恢复当前已应用预设的默认外观和法线参数，保留绘制范围、时间路径及效果强度。它不等于恢复手工修改过的共享节点组内部结构。

### 7.2 效果强度

**效果强度** 是当前目标的整体显示量：

- 0：查看原始外观，保留绘制记录。
- 1：按已记录的范围和权重显示效果。
- 中间值：降低整体效果程度。

效果强度与笔刷强度不同。笔刷强度影响本次记录，效果强度用于调整已有结果；某处只以较低笔刷强度绘制时，将效果强度设为 1 也不会把该处的记录自动改为满强度。

### 7.3 默认石头

用于带颗粒和凹凸的石质表面。

| 参数 | 作用 |
| --- | --- |
| 石头颜色 | 调整石材底色 |
| 粗糙度 | 较高值使反光分散，较低值使反光集中 |
| 凹凸强度 | 控制石材表面凹凸的视觉强弱 |
| 颗粒密度 | 控制程序化纹理的密度；数值增大时颗粒更细密 |

调整颗粒密度时，应在最终取景距离检查效果。过细的纹理在远景中可能不明显。材质中的凹凸属于着色细节，不改变模型轮廓。

### 7.4 人形硬质化

用于光滑、带高光的非金属树脂表面。

**配色方式** 分为三种：

| 方式 | 颜色来源 |
| --- | --- |
| 模型原色 | 使用插件识别到的模型基础纹理与颜色 |
| 统一颜色 | 使用“树脂颜色”指定的颜色 |
| 叠加颜色 | 将模型原色与指定颜色按比例混合 |

在 **叠加颜色** 模式中，**颜色叠加比例** 为 0% 时使用模型原色，为 100% 时使用自选颜色。该比例只改变配色，不改变绘制范围。

| 参数 | 作用 |
| --- | --- |
| 树脂粗糙度 | 控制树脂表面的反光清晰程度 |
| 高光强度 | 控制表面高光强弱 |
| 透明涂层 | 调整表面清漆层的强度，不是让整个人物透明的比例 |
| 涂层粗糙度 | 控制清漆层反光的锐利或柔和程度 |

复杂材质的原色无法直接识别时，插件可能使用材质显示颜色，并提示“部分复杂材质使用显示颜色”。此时应检查实际外观，不应将回退结果当作原着色器的完整复制。

树脂高光依赖灯光和环境反射。检查光泽时应关闭轻量预览。

### 7.5 冰霜冻结

冰霜预设在模型外增加独立冰壳及附着冰锥，并保留人物原材质。冰层和冰锥的显示范围随主面板记录的静态涂抹或时间路径变化。

#### 冰层外观

| 参数 | 作用 |
| --- | --- |
| 冰层通透度 | 调整冰层的通透程度；提高后更容易看清内部模型 |
| 白霜覆盖量 | 控制白霜的覆盖强弱；提高后表面更白、更雾化 |
| 冰色叠加比例 | 控制指定冰色对外观的影响程度 |
| 冰层颜色 | 指定冰层色调 |
| 冰面粗糙度 | 控制冰面反光的清晰程度 |
| 冰层厚度 · 高度% | 控制冰壳偏离模型表面的厚度 |

希望保留清晰的人物颜色时，可提高通透度、降低白霜覆盖量和冰色叠加比例，再调整冰面粗糙度。通透效果仍会受到灯光、渲染设置、原材质和冰层重叠的影响。

#### 冰锥形状与数量

| 参数 | 作用 |
| --- | --- |
| 冰锥外形 | “圆润冰锥”为平滑锥状，“棱面冰晶”为有棱面的晶体 |
| 冰锥候选数量 | 每个网格 0—1000，默认 180；候选位置中只有满足绘制范围等条件的部分显示 |
| 冰锥长度 · 高度% | 控制冰锥长度 |
| 冰锥半径 · 高度% | 控制冰锥粗细 |
| 大小随机程度 | 控制冰锥之间的尺寸差异；0 时尺寸差异最小 |
| 冰锥通透度 | 单独控制冰锥的通透程度 |

候选数量不等于最终可见数量。绘制面积较小、存在排除材质或其他筛选条件时，显示数量会减少。数量设为 0 可保留冰层而不显示冰锥。

厚度、长度和半径按对应网格的高度百分比计算，并非以毫米为单位。多部件角色的各网格可能有不同高度基准，相同数值不一定得到完全相同的实际尺寸。

#### 冰锥朝向

**原有自然朝向**：在沿表面向外和世界向下之间混合。通过 **朝向向下比例** 调整：0 沿表面向外，1 向世界下方垂挂，中间值混合两种方向。

**统一指定方向**：全部冰锥朝指定方向，使用方向坐标系、水平角和仰俯角设置。

**指定方向 + 随机**：围绕指定方向随机偏转，另有 **随机最大偏转角** 和 **朝向随机种子**。

| 方向设置 | 含义 |
| --- | --- |
| 世界坐标 | 方向相对场景；模型物体旋转后仍以场景方向为基准 |
| 模型局部坐标 | 方向相对模型物体，随物体旋转 |
| 水平角 | 0° 朝 +X，90° 朝 +Y，180° 朝 −X |
| 仰俯角 | 90° 向上，0° 水平，−90° 向下 |
| 快捷方向按钮 | +X、−X、+Y、−Y、向上、向下 |
| 随机最大偏转角 | 0° 为完全统一；数值增大时方向更分散，180° 为全方向随机 |
| 朝向随机种子 | 更换随机朝向组合，不重新分布位置或改变大小 |

#### 分布与局部排除

**分布种子** 控制冰锥位置分布。修改后点击 **重新分布冰锥** 生效；它与“朝向随机种子”不是同一个设置。

**排除材质关键词** 根据材质名称筛选，用逗号分隔。例如输入 `眼,脸`，点击 **重新分布冰锥** 后，名称包含这些关键词的材质区域不生成冰锥。该设置只排除冰锥，不清除该处的冰层涂抹。

**重新分布冰锥** 重建附着位置，不修改已有涂抹范围或时间路径。若只想微调朝向，不必重新分布。

检查冰霜最终外观时应关闭轻量预览。旧贴图蒙版的维护结果不能代替主面板绘制的冰锥覆盖记录。

### 7.6 黄金

用于抛光金属或磨砂金属外观。

| 参数 | 作用 |
| --- | --- |
| 黄金颜色 | 调整金属底色 |
| 金属度 | 1 为金属反射；降低后混入非金属响应，不是黄金覆盖比例 |
| 黄金粗糙度 | 较低值呈现较清晰的镜面反射，较高值呈现磨砂质感 |
| 金属微纹理强度 | 调整程序化细小凹凸；0 关闭这层微纹理 |
| 金属微纹理尺度 | 数值越大，纹理越细密 |

金属依靠环境和灯光形成反射。表面显得暗淡时，应同时检查粗糙度、灯光、环境和预览模式，不宜只通过提高颜色亮度处理。检查黄金光泽时应关闭轻量预览。

<a id="normals"></a>
## 8 人物细节与材质纹理

入口位于 **材质预设 → 人物细节 + 材质纹理**。

插件通过节点混合已识别的原材质法线或凹凸，以及效果材质自身的纹理细节。

| 控件 | 作用 |
| --- | --- |
| 人物细节强度 | 在效果区域保留已识别的原法线或凹凸；0 关闭这部分细节，1 完整保留 |
| 材质纹理强度 | 调整效果材质本身的法线或凹凸叠加强度；0 关闭这部分纹理细节 |
| 启用 / 重新识别人物法线 | 初次处理旧工程，或修改原材质节点后，重新建立识别和混合连接 |

例如，石化后仍希望保留服装缝线，可保留人物细节强度，再调整石材凹凸及材质纹理强度。若不希望原法线细节影响光滑表面，可降低人物细节强度。

关闭人物细节强度不会消除模型已有的几何起伏；这两个参数控制的是着色细节。

面板状态提示含义如下：

- **已识别人物法线 / 凹凸**：已找到可使用的原细节连接。
- **无原细节的材质使用表面法线**：该材质没有已识别的法线或凹凸输入，按模型表面正常着色。
- **部分复杂材质无法唯一识别**：原材质存在无法可靠确定的分支，使用表面法线回退。
- **旧工程：点击上方按钮启用**：需要执行一次重新识别。

重新识别不重置预设参数、涂抹或时间路径。法线效果应在完整材质模式下检查。

<a id="presets"></a>
## 9 自定义预设管理

打开 **预设管理 · 添加 / 删除**。自定义预设保存在本机预设库，重启 Blender 后仍可使用；添加预设和将预设应用到模型是两个独立操作。

### 9.1 保存当前材质外观

1. 选择已经初始化的目标，并调整当前效果材质。
2. 在预设管理中，将 **保存来源** 设为 **当前材质外观**。
3. 填写新预设名称。
4. 点击 **添加为新预设**。
5. 需要使用时，再选择该预设并点击 **应用材质预设**。

保存内容为目标当前效果材质的节点及参数，不包含涂抹范围和时间路径。多网格目标取第一个有效网格的效果材质，不将不同部件的多套外观合成一个预设。需要精确保存某个部件时，先将它单独设为目标。

冰霜包含独立几何，不能仅通过“保存当前材质外观”保存完整冰层与冰锥配置。保留这类配置应保存 `.blend` 工程。

### 9.2 保存自制节点组

1. 在着色器编辑器中准备完整的着色器节点组。
2. 确认组具有 **着色器输出**，并且该输出在组内部已经连接。
3. 在预设管理中，将 **保存来源** 设为 **自制节点组**。
4. 选择节点组，填写名称。
5. 如果组有多个着色器输出，在 **着色器输出** 字段填写要使用的输出名称。
6. 点击 **添加为新预设**。

这里保存的是组内部内容及**组接口默认输入值**。默认输入值是节点组接口为新建组节点提供的初始数值，不一定等于材质中某个组节点后来调整过的数值。

例如，组接口中“粗糙度”的默认值为 0.5，材质中某个组节点被调到 0.2。使用本节入口保存时，取组接口的默认设定；若要保留 0.2，应使用下一节的入口。

### 9.3 保存选中组节点的实际输入值

1. 在 **着色器编辑器** 中选中要保存的组节点，使其成为当前活动节点。
2. 按 N，打开 **ASFR → 材质预设**。
3. 点击 **将选中节点组存为预设**。
4. 在弹出的窗口中填写名称；必要时指定着色器输出。
5. 确认保存。

该入口保留选中组节点当前的输入数值。若组节点输入有外部连线，插件会拒绝保存并提示先将相关节点一起收入组内，以免遗漏输入依赖。

### 9.4 保存要求

预设保存时会复制节点组及嵌套组，并尝试打包使用的贴图，不覆盖源节点组。同名预设会追加编号，例如“我的石材 (2)”，而不是覆盖已有条目。

准备节点组时应满足以下条件：

- 着色器输出明确且已连接。
- 不依赖场景中的物体或集合；坐标可改为 UV 或生成坐标。
- 节点组内没有需要保留的动画或驱动。
- 使用的贴图可读取、可打包；序列和视频贴图不适用于该保存流程。
- UDIM 图块有未保存修改时，先保存图块。
- 外部 OSL 脚本应先转为内部文本。

保存失败后，按报错指向的节点或贴图处理，再次保存。

### 9.5 删除与恢复

选择不需要的自定义预设，点击 **删除选中预设**。四款内置预设受保护，不能通过此按钮删除。

删除只移除库中的可选条目，不改变模型上已经应用的效果。文件会移入预设目录下的 `.deleted` 回收区。

点击 **恢复最近删除** 可恢复最近一次移入回收区的预设。恢复后，列表会选中该条目，但不会自动改变模型外观。回收区被手工清空后，按钮无法再恢复其中的文件。

### 9.6 工程内预设、本机预设及备份

**显示工程内预设** 默认关闭。开启后，列表可显示当前工程携带、尚未存入本机库的自定义预设。显示这些条目不会自动将它们写入本机目录。

点击 **预设目录** 打开本机库。备份或迁移自定义预设时，将同名的 `.blend` 和 `.json` 文件一并复制；放入另一台电脑对应的预设目录后，点击 **刷新**。

分享前应确认预设所用贴图和节点资产允许再分发。保存到本机库与拥有对外配布权限是两回事。

### 9.7 清理旧版闲置石化组

**清理旧版闲置石化组** 用于删除插件生成、没有引用且没有保留标记的闲置节点组。正在使用的材质和用户自行创建的节点组不属于该清理范围。

不要根据节点组名称后面的编号直接判断其是否无用；模型和预设可能仍在引用它。需要清理时使用此按钮，并保留工程备份。

<a id="preview"></a>
## 10 轻量预览

点击 **开启轻量预览** 后，插件简化当前目标的角色和效果材质，保留绘制范围及时间变化，便于连续绘制和拖动时间轴。

按钮会变为 **轻量预览中 · 切回完整材质**。再次点击即可恢复完整外观。

轻量模式用于检查覆盖区域和时间推进，不用于判断树脂高光、金属反射、冰层通透度或法线细节。调整这些参数后，应切回完整模式检查。

保存工程和正式渲染时，插件会自动临时恢复完整材质；操作结束后可能继续保持轻量预览。切换目标或撤销等操作也可能使轻量预览退出，可按需要重新开启。

模型面数、修改器、材质复杂度、路径数量和冰锥数量都会影响操作速度。轻量预览主要减轻材质预览负担，不会减少原模型的面数。冰霜场景可同时降低冰锥候选数量。

<a id="modifiers"></a>
## 11 修改器兼容设置

插件可针对固定的最终网格建立兼容绘制数据。镜像、阵列等修改器生成的各部分，可在最终网格上分别涂抹。

### 11.1 绘制前检查

面板出现 **修改器兼容：直接绘制最终网格** 提示时，应先确认：

1. 生成网格的修改器在视图和渲染中的显示开关一致。
2. 细分表面、多级精度等修改器的预览级别与渲染级别一致。
3. 场景启用“简化”时，视图和渲染的细分上限一致。
4. 修改器参数不会在动画中改变网格生成结果。

尚未建立兼容绘制数据时，可点击 **预览匹配渲染设置**，按渲染配置调整相关视图开关和预览细分级别。渲染细分较高时，这一步可能增加预览负担和首次准备时间。

### 11.2 绘制后保持设置稳定

绘制后，应保留建立绘制数据时的拓扑、修改器生成设置及细分级别。若面板提示设置已改变，先恢复绘制时的设置。

插件添加的 **石化 · 修改器兼容** 修改器应留在修改器列表末尾，并保持视图和渲染显示开启。内部绘制数据对象也应保留。

兼容检查会对无法处理的修改器、生成网格参数动画、带动画参照物的布尔、自适应细分或设置不一致给出提示。出现提示时，先处理对应设置，再继续绘制；不要通过删除兼容修改器来消除提示。

<a id="save"></a>
## 12 保存与工程迁移

### 12.1 保存当前工程

完成绘制后点击 **保存工程和石化蒙版**：

- 已有文件路径的工程保存到当前 `.blend` 文件。
- 尚未保存的工程打开保存窗口，选择位置后确认。
- 插件使用的石化蒙版会打包进工程。

时间路径、范围属性和外观参数随工程保存。本机自定义预设库则单独存放；工程能显示某个已应用预设，不代表另一台电脑的本机库也已有对应条目。

### 12.2 迁移到另一台电脑

1. 在接收端安装并启用相同版本插件。
2. 完成本次绘制并保存 `.blend` 工程。
3. 检查模型所需的原始贴图、其他外部资源及相关插件是否齐全。
4. 如需继续从本机库选择自定义预设，按第 9.6 节单独迁移预设文件。
5. 在接收端打开工程，检查目标范围、材质、时间轴及修改器提示，再继续工作。

插件的“保存工程和石化蒙版”按钮不应视为对场景内全部外部资源的完整打包。分享工程前，应单独检查模型贴图和其他依赖。

<a id="legacy"></a>
## 13 旧版工程维护

入口：**高级工具 → 旧版工程维护**。

该面板用于修补早期工程已有的贴图蒙版，包含：

- **修补旧贴图蒙版**。
- **擦除旧贴图蒙版**。
- 绘制状态下的 **笔刷大小**、**笔刷强度**。
- **结束旧蒙版绘制**。

先选择带有旧石化蒙版的目标，再执行修补或擦除。完成后点击 **结束旧蒙版绘制**，随后保存工程。

旧蒙版修补不记录新版时间路径，也不擦除新版路径。新的表面绘制应使用主面板 **使用方法 → 表面涂抹**，以便使用同一套时间路径和多角度操作。

## 14 常见问题

### 14.1 选中模型后只有初始化按钮

当前目标尚未初始化，或目标范围中有未初始化网格。确认“本次范围”无误后，点击 **初始化 / 升级目标模型**。

### 14.2 衣服和身体为什么一起产生效果

先检查是否使用 **球形穿透**，以及是否开启 **包含模型子物体**。球形范围内的目标网格会一起生效。只想处理外层时改用表面涂抹；只想处理一个部件时，将目标直接设为该网格。

### 14.3 画了但看不到最终材质

依次检查：

1. 多角度连续绘制是否仍在等待 Enter 完成。
2. 当前时间帧是否早于路径开始帧。
3. 路径是否启用，或被其他独显路径筛掉。
4. 效果强度是否为 0。
5. 是否开启轻量预览。
6. 预设是否已经点击应用，而不只是选中了下拉框。

### 14.4 绘制边缘呈块状，或细小部位画不上

两种主面板笔刷都依赖网格密度。先确认笔刷半径是否过小。需要更高精度时，应在正式绘制前确定合适的网格密度及固定细分级别，而不是画完后任意改变拓扑。

### 14.5 松开左键后还不能操作其他按钮

多角度连续绘制中，松开只是暂停。按 Enter 完成或按 Esc 取消后，再操作面板。

### 14.6 三个区域没有同时从左向右变化

使用 **各段同时推进**，并在每个区域结束时松开左键，让它成为独立笔段；三个区域全部绘制完后再按 Enter。若使用“同时渐变”，得到的是整体一起淡入，不是各段沿方向推进。

### 14.7 擦除后其他帧也发生变化

擦除修改整条路径的覆盖记录，所以所有帧都会受到影响。只想操作指定路径，应先勾选路径，再选 **勾选路径** 擦除范围。

### 14.8 冰锥数量少于设置值

设置的是候选数量。实际显示还受绘制范围、时间进度、材质排除和覆盖权重等条件影响。先到路径结束帧检查，并确认效果强度及排除关键词。

### 14.9 修改分布种子或排除关键词后没有变化

点击 **重新分布冰锥**。若修改的是 **朝向随机种子**，它只改变随机朝向，不改变附着位置。

### 14.10 没有法线贴图会怎样

该材质使用模型表面法线，效果材质仍可呈现自身纹理。面板出现“无原细节的材质使用表面法线”是状态说明，不是报错。

### 14.11 删除预设后，模型外观为什么还在

删除预设只移除本机库条目，不移除工程中正在使用的效果。要改变外观，选择另一个预设并应用；要找回库条目，点击 **恢复最近删除**。

### 14.12 操作卡顿时先检查什么

先开启轻量预览，并检查模型面数、当前细分级别、路径数量及冰锥候选数量。批量初始化或切换多网格材质时，插件会暂存数据以便失败回滚，因此可能出现短时等待和额外内存占用。
